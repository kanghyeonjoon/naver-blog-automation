# 네이버 블로그 자동화

관심분야 키워드 → 네이버 뉴스·인기 블로그 글감 수집 → AI가 자연스러운 블로그 글 작성 → 무료 스톡 사진 자동 배치 → 스마트에디터 서식(소제목·인용구·구분선·태그) 적용해 자동 발행.

## 설치

```bash
npm install
npx playwright install chromium
```

## 실행

```bash
npm start
```

→ http://localhost:3580

## 사전 준비

1. **Claude 구독 로그인**: 터미널에서 `claude` 실행 → `/login` (AI 글 생성에 구독 계정 OAuth 사용, API 키 불필요)
2. **네이버 로그인**: 대시보드 우측 상단 "네이버 로그인" 버튼 → 열린 브라우저에서 직접 로그인 (세션은 `data/auth/`에만 저장)
3. **이미지 API 키** (선택): 설정 탭에서 Pexels 또는 Pixabay 무료 키 등록 — 없으면 이미지 없이 발행
4. **스타일 가이드** (선택): `data/persona/` 폴더에 PDF 또는 md 파일을 넣으면 그 문체로 작성

## 사용 흐름

① 글감 수집 (키워드) → ② AI 글 생성 → ③ 검토·수정 → 발행 또는 대기열 → ⏱ 간격 자동 발행

## 초안 마커

| 마커 | 의미 |
|---|---|
| `[H] 텍스트` | 소제목 (크게+굵게) |
| `[QUOTE] 텍스트` | 인용구 |
| `[IMG:n]` | n번째 이미지 위치 |
| `[HR]` | 구분선 |

※ 첫 발행은 설정 탭에서 공개 설정을 "비공개"로 두고 테스트한 뒤, 서식이 잘 나오는지 확인하고 전체공개로 바꾸는 것을 권장합니다.
